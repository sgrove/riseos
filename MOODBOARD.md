# riseos.com Blog Hero Image Moodboard

## Style: "Zen Graffiti"
Fusion of Japanese zen garden aesthetics with Jet Set Radio's cel-shaded street art energy.

## Color Palette
- **Moss Green:** #3d5a3d (dark), #7a8b72 (mid), #9ab08f (light)
- **Stone Gray:** #4a4a4a (dark), #8a8a8a (mid), #c0c0c0 (light)  
- **Amber/Gold:** #dab478, #f0d090
- **Cream:** #faf8f3, #f5f0e8
- **Accent:** #2d3d2d (near black for outlines)

## Visual Elements
- **Textures:** Raked sand patterns, moss on stone, water ripples, spray paint spatter
- **Shapes:** Organic rock forms with bold cel-shaded outlines
- **Lighting:** Soft golden hour, misty atmosphere
- **Composition:** Asymmetric balance (Japanese garden principles)

## Art Direction
- Flat color areas with 2-3px dark outlines
- Subtle halftone gradients (screen print aesthetic)
- Spray paint texture at edges
- Each image features a zen element (rock, water, moss, lantern, sand, leaves)
- Subtle tech motif integrated (circuit traces in sand patterns, code fragments as texture)
